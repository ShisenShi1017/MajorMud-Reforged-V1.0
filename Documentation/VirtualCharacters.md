# Virtual Character Profiles

DataSimVer0007 introduces virtual player profiles so simulations can evaluate access as a function of player state.

These profiles are not original runtime proof. They are conservative expected-model inputs designed to discover behavior implied by `/Data`.

Profiles:

1. Level 1 Human Warrior — new-player baseline, no assumed keys or flags.
2. Level 10 Explorer — early/mid exploration with common-key assumptions.
3. Level 20 Spellcaster — spell/travel clue testing, spell logic still inferred only.
4. Level 40 Advanced Character — advanced access and level-gate classification.
5. Level 60+ Veteran — endgame-level access classification.
6. Diagnostic Character — all-items/all-flags diagnostic profile; not representative of real play.
