# Repository Rules

**CodeUpdate 0125**

1. Librarium is authoritative.
2. `/Data` is generated-only runtime output.
3. `ImportedDatabases` remains until Librarium completion is explicitly declared.
4. Runtime must not write authoritative gameplay definitions.
5. Client is read-only and world-filtered.
6. Classic world definitions are evidence-locked.
7. Custom and AI worlds use validated Librarium overlays.
8. Every runtime export must trace to a Librarium generation contract.
9. Open conflicts remain documented until resolved: DR, dodge order, special/backstab defense order.

## CodeUpdate 0127 Overlay Rule

Classic is the locked base branch. Custom and AI worlds are generated by merging validated overlays with their selected base Librarium branch. /Data remains generated output and must not be hand-edited.
