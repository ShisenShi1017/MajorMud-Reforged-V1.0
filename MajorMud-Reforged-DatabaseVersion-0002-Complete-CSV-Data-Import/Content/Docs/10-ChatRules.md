# Chat and Development Rules

These rules help future ChatGPT sessions continue the project correctly.

- Use the uploaded ZIP/GitHub project as source of truth for code.
- User-provided summaries replace the missing architecture PDF.
- Treat MajorMud Reforged as a professional software project.
- Use database versions for converted data releases.
- Use patches for code/tool/editor/client changes.
- Database versions must avoid duplicate records.
- Every database version must include docs, verification reports, release notes, and a handoff update.
- Do not claim a feature, patch, or database version is complete unless it was actually created and verified.
