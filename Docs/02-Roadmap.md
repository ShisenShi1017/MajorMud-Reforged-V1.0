# MajorMud Reforged Roadmap

Last Updated: 2026-06-27

## Development Phases

### Phase 1: Standalone Server

Primary goal: stable standalone MajorMud server.

Planned focus areas:

- Server startup/shutdown stability.
- Character creation and login.
- Save/load reliability.
- Room movement.
- Commands.
- Combat.
- Monsters.
- Items.
- Shops.
- Spells and skills.
- Admin tools.
- Imported database support.

### Phase 2: Host/World Editor

Primary goal: safe editor for game content.

Planned focus areas:

- Data validation.
- Room editor.
- Monster editor.
- Item editor.
- Race/class editor.
- Spell/skill editor.
- Message editor.
- Import/export tooling.
- Documentation of database fields.

### Phase 3: Client Work

Primary goal: modern client inspired by MegaMud 2.0.

Planned focus areas:

- PC client improvements.
- Android client exploration.
- Mapping.
- Triggers.
- Aliases.
- Macros.
- Profiles.
- Scripting.
- UI themes.

## Roadmap Rule

The roadmap is a planning document, not an implementation claim. Items listed here are not complete unless recorded in release notes or patch history.
