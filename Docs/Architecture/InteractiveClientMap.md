## Vision

The Client map should become the primary navigation workspace.

The Librarium remains the knowledge, planning, and analysis workspace.

## Interactive Map

Every discovered room may eventually be selected to display:

- Room description.
- Exits.
- NPCs.
- Monsters.
- Shops.
- Personal notes.
- Favorite markers.
- Spawn timer information when host policy allows it.
- Navigate Here actions.

## Map Layers

Optional layers may include rooms, exits, zone boundaries, shops, banks, trainers, bosses, quest NPCs, party members, notes, favorites, and spawn timers.

## Renderers

Future map renderers may include Classic, node map, modern vector, zone overview, and builder artwork overlay modes.

## Boundary

This is a planning placeholder only. CodeUpdate-0057 does not implement live client map behavior, routing, spawn timers, editor behavior, or gameplay systems.
