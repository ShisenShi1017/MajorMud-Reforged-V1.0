## What this archive proves

MudPlay supplies a broad, production-shaped implementation of nearly every major MegaMUD client category and an MMExplorer-like game-data browser. It is therefore an excellent implementation reference and test donor.

It does **not** by itself prove 100% MegaMUD or MMExplorer parity. Its documentation explicitly describes a “MegaMUD-style automation suite,” and it contains features and assumptions for multiple realms/BBS hosts. Parity must be proven against our target feature matrix and live MajorMUD protocol/output.

## Reforged integration rules

1. Keep Reforged's server and generated `Data/Classic` catalogs authoritative.
2. Port headless parsers, models, decision engines and tests before porting Avalonia views.
3. Rebuild UI in WPF and bind it to Reforged services; do not introduce a second UI framework.
4. Exclude BBS login navigation and BBS credential storage because Reforged connects directly to its own server.
5. Preserve the global automation freeze until every command-producing engine has deterministic safety, cancellation, reconnect and user-override tests.
6. Enable automation by independently controllable capability switches, with Emergency Stop overriding every switch.
7. Retain MudPlay's MIT notice for any copied or substantially derived code.

## Import sequence and acceptance gates

1. Terminal/parser reconciliation: ANSI, CP437, Telnet negotiation, prompt/stat/room/combat parsing.
2. Read-only MMExplorer parity: searchable browser, maps, record cross-links, overlays, spell/quest/trainer/item views.
3. Navigation: graph tracking, GOTO, loops, action exits, door/trap/hidden-exit handling and recovery.
4. Character state: inventory, equipment, currency, spells, conditions, party and session statistics.
5. Automation engines: combat, healing, buffs, loot/cash, training, quests and remote party coordination.
6. Calculators/workshop and diagnostics.
7. Full regression against generated Classic data and recorded runtime transcripts.
8. Remove the global freeze only when all command-producing families pass and every independent switch plus Emergency Stop is wired.

## Current result

MudPlay should be incorporated as a licensed implementation reference, not embedded wholesale. Reforged currently does not have 100% MegaMUD/MMExplorer client parity because its command-generating automation remains deliberately frozen. This audit establishes the source identity, compatibility boundary, feature map and safe order needed to complete that work.
