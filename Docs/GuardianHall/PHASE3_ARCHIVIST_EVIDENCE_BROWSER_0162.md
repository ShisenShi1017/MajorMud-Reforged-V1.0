# Guardian Hall Phase 3-0162 — Archivist Evidence Browser

Brother Caelum now exposes an indexed, read-only evidence browser over decoded queue records and evidence nodes.

Search covers file names, source paths, evidence types, SHA-256 identities, decoded findings, confidence, and relationship text. Results are capped at 250 and require every entered search term to match. Selecting a result opens direct relationships plus reverse references from other evidence nodes.

The browser does not edit source evidence, generated runtime data, or Librarium. Existing decode, report, Codex export, and saved-evidence workflows remain preview-only.
