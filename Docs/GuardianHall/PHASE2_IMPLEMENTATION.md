# Guardian Hall Phase 2

Guardian Hall now exposes five independent role workspaces while Forge and Borin remain separate.

- Realm Keeper: global server/world coverage, monitoring, thresholds, reports, maintenance, health, activity, and timeline. No world or character selector.
- Wanderer: server/world/realm/character mission controls, exploration and field policies, mission queue, route, inventory, and progress.
- Analyst: character-free analysis targets, scopes, sources, ranges, graphs, trends, frequency, output, and report export.
- Worldsmith: character-free test-realm proposal, content scopes, constraints, modes, approval, preview, and simulation.
- Archivist: file/folder/drag-drop intake, decode queue, evidence confidence, relationship and Librarium previews, Markdown/HTML/JSON/PDF reports, Codex ZIP export, and editable local tool registry.

Persistence is stored in `GuardianHall/guardian-hall-state.json` beneath the application data root. Librarium output is preview-only and no service silently overwrites canonical knowledge.
