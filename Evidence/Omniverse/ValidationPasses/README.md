# Omniverse Validation Passes

Suggested identifier format: `OVGN-####`.

Each pass must identify the exact source artifacts, compare them with authoritative or corroborating evidence, and end with one of:
- Verified
- Corroborated
- Conflicting
- Rejected
- OmniMUD enhancement (not stock)

Initial candidates:
- OVGN-0001: Combat wound states and monster attack selection
- OVGN-0002: Monster spell resistance and energy fallback
- OVGN-0003: Aggro target give-up counter
- OVGN-0004: Daily maintenance sweeps
- OVGN-0005: Dragon hide legacy mapping
