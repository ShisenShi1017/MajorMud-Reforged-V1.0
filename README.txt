MajorMUD Reforged v2.2

Run:
1. Double-click Run-Server-Only.bat
2. Wait for SERVER_READY port 2323
3. Double-click Test-LocalClient.bat

Changes in v2.2:
- New characters start at level 1.
- Max level remains 100.
- Admin test commands added for level, XP, training points, gold, HP, and stats.
- Shared Data folder remains the source for server/editor/client behavior.

Admin commands while playing:

admin setlevel 10
admin addlevel 1
admin xp 500
admin addxp 100
admin points 25
admin addpoints 10
admin gold 999
admin hp 20
admin maxhp 100
admin stat str 25

Normal training:
Go east to Training Yard, type train/menu, adjust numbers, then save.
