# Librarium-0001 — Core Knowledge Graph Foundation

This milestone pivots Reforged from separate runtime/data/documentation tracks into one evidence-driven knowledge graph.

## Core rule

The Librarium is the authoritative knowledge layer. Runtime, server, editor, validation tools, documentation, custom worlds, and AI worlds consume the graph instead of maintaining separate interpretations.

## Evidence states

- **Verified** — direct canonical source or validated authoritative evidence.
- **Derived** — supported by extracted relationships or multiple sources but not fully proven as an ordered mechanic.
- **Observed** — gameplay/runtime/user-confirmed observation awaiting database path validation.
- **Hypothesis** — theory only; not runtime truth unless explicitly selected.
- **WorldOverride** — custom/re-forged world overlay change; never corrupts Classic base graph.
- **AIProposal** — AI-generated content pending host approval.
