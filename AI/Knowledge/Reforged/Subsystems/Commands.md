# Commands

- Classic command abbreviations are required across applicable commands, including examples such as `g`, `eq`, and abbreviated shop item names.
- Ordinary non-command text is room speech rather than an automatic unknown-command failure.
- `BRIEF` and `VERBOSE` are client/server-facing command requirements where implemented by Classic behavior.
- Command parsing, contextual resolution, generated command identity, live consumer behavior, help/menu coverage, and validation are separate trace stages.
