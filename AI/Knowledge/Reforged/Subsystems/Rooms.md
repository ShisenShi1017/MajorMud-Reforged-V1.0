# Rooms and Exits

- Room, exit, door, trap, timed-exit, description, and movement behavior must remain data-driven and traceable from decoded records into live room consumers.
- A room record existing in generated data does not prove movement, traps, search, or display behavior is live.
- Map discovery and client conveniences must not mutate authoritative server room state.
- Placeholder rooms or invented geography are not acceptable parity evidence.
