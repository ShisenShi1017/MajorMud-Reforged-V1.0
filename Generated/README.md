# Generated Outputs

Generated outputs are compiled/exported from the Librarium canonical knowledge graph.

- `/Data` is the compatibility runtime data surface.
- `/Generated/RuntimeData` is reserved for compiler/export output.
- `/Generated/ValidationReports` is reserved for generated validation output.
- `/Generated/Documentation` is reserved for generated documentation.

Do not treat generated output as canonical. Update `/Librarium` first, then regenerate.
