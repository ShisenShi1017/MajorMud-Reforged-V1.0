# Behavioral Recovery Runtime Boundary

Build0021 provides static/inferred behavioral inputs for the MajorMUD Reforged simulator.

These inputs may be used for expected-model simulation, but they are not proof of original Worldgroup runtime behavior unless the confidence field is `verified_from_data` and the rule is purely data-backed.

Anything marked `runtime_required` must stay unresolved until live runtime observation, original executable tracing, or stronger decoded source evidence is available.
