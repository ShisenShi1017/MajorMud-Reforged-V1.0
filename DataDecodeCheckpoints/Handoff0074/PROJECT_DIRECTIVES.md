# Project Directives

1. `/Data` is the runtime source of truth.
2. Original MDB/DAT/WCC/WBB/Worldgroup/MMExplorer/HTTrack data is reference/provenance only.
3. Runtime must not depend on original imported data files.
4. Preserve unknown fields and provenance.
5. Repository docs are architecture source of truth.
6. Do not duplicate architecture/design docs unless explicitly requested.
7. All patch ZIPs must be cumulative.
8. The Forge is the official client name.
9. Development, administration, and world editing belong on the host/server.
10. Every claim must be tied to evidence and confidence.
