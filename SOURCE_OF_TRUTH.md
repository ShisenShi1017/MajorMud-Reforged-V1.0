# MajorMUD Reforged Source of Truth

**CodeUpdate 0125**

The Librarium is the authoritative source for worlds, mechanics, evidence, and generation contracts.

`/Data` is generated runtime output only. It is not edited manually and is not the source of truth.

`ImportedDatabases` is retained as the evidence archive until the Librarium is declared 100% complete by project decision.

Runtime gameplay code remains an execution layer. Host/editor workflows modify the Librarium, validation/compiler workflows generate `/Data`, and clients receive read-only world-filtered views.

## CodeUpdate 0127 Overlay Rule

Classic is the locked base branch. Custom and AI worlds are generated by merging validated overlays with their selected base Librarium branch. /Data remains generated output and must not be hand-edited.
