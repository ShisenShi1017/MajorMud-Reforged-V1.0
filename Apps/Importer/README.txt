MajorMud Reforged - Importer
================================

Purpose
-------
Native import and verification app for CSV, MegaMud MP, and original MajorMud runtime data. No Access/OLEDB dependency.

Executable rule
---------------
Compiled executables for this component must live in their own folder under Bin/Windows/Importer.

Status
------
Foundation folder only. No executable is claimed in this update.
