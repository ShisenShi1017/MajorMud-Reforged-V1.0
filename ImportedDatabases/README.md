# Imported Databases

Imported/native/reference databases are local-only archival evidence and are not committed to Git.

The authoritative gameplay source is `Librarium/`. Runtime data is generated into `Data/`.

Local archive expected:

- `Archive/ImportedDatabasesAndEvidence.LocalOnly.rar`

Extract that archive back to the repository root only when a future decode, provenance audit, or source-retirement review needs the original imported/reference material.
